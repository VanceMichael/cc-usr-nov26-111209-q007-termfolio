# 本地字符台账

真实交互入口为 `python3 -m termfolio.ledger --update-after-details 1`，需连接 PTY，固定屏幕24行80列。中文为本程序逻辑单格字符，不实现宽字符规则。支持 ANSI CUP、ED2、EL0、SGR 和 CR/LF；字符可能按多次系统写入交付。回放 fixture 仅用于屏幕投影测试，不能代替交互采集。

n/p 翻页，j/k 移动焦点，o 打开当前行详情，b 返回，q 退出，模态提示按空格确认。列表每页三行，相邻页重叠一行，详情返回后焦点回第一行。列表包含摘要，详情才有完整箱号及备注；屏幕第24行是版本、页号和就绪信息，第2行时钟每0.2秒局部刷新，不应作为完成翻页依据。m 和 s 是受保护写入入口，本地程序会显示禁止访问，采集不能触发。输入非法按键时只更新状态行。

--update-after-details=1 会在第一次详情返回后弹出资料更新提示，确认后改为v2并重置首页；v2新增一个箱号。参数为0时版本稳定。源程序直接合成台账用于隔离演练；生产采集只依据 PTY 屏幕及合法按键，不读取 ledger.py 的行记录作为输入。项目不包含网络终端协议、真实账户或外部设备。
